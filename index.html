Cognitive Delegation Analysis Framework (CDAF)

Autor: IRAÊ CÉSAR BRANDÃO - Psychopedagogical Researcher and Developer
Publication Date: 18 Mar. 2026.

Este framework foi desenvolvido para analisar, de forma estruturada, os efeitos da mediação da Inteligência Artificial na produção científica, considerando dimensões como autonomia cognitiva, integridade epistêmica e lacuna de compreensão.

Como Utilizar o Framework CDAF

Etapa Ação Descrição
1 Inserir Dados do Artigo Preencha a data, o nome da publicação e a problemática principal abordada no artigo.
2 Avaliar Dimensões Atribua valores de 1 a 5 para Autonomia Cognitiva, Integridade Epistêmica e Lacuna de Compreensão com base na análise realizada.
3 Adicionar Observações Inclua observações qualitativas para justificar as pontuações atribuídas ou destacar aspectos relevantes.
4 Salvar Registro Clique em “Adicionar” para armazenar a análise. Os dados são salvos automaticamente no navegador.
5 Comparar Artigos Utilize o gráfico de barras para identificar padrões, semelhanças e diferenças entre múltiplas análises.
6 Selecionar para Análise Detalhada Clique em uma linha da tabela para visualizar o artigo específico no gráfico radar.
7 Interpretar Resultados Analise as relações entre as dimensões para identificar dependência cognitiva, coerência ou lacunas de compreensão.
8 Exportar Dados Baixe os resultados em formato CSV para análises adicionais ou inclusão em trabalhos acadêmicos.
9 Reiniciar Análise Utilize o botão de limpeza para iniciar um novo conjunto de dados quando necessário.

Observação: As pontuações devem ser atribuídas com base em leitura crítica e alinhamento teórico. O framework possui caráter interpretativo e foi concebido para apoiar análises comparativas estruturadas, não para produzir medições absolutas.
